# Cinescope
Cinescope is modern React application for discovering and exploring movies using an external movie API.
It focuses on clean UI/UX, responsive design, and a well‑structured front‑end architecture.

##Live Demo
https://cinescope-movie-app.netlify.app

## Features
- Movie search with instant results  
- Detailed movie pages (poster, overview, rating, genres)  
- Add movies to favorites (local state or localStorage)  
- Fully responsive design  
- Fast API fetching using async/await  
- Modern and consistent UI styling
